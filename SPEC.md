# Smoggle — IDE Prompt Spec v4
## AI Performance Toggle Dashboard for macOS (Apple Silicon)

---

## Project Overview

Build a web-based dashboard called **Smoggle** that allows remote toggling of macOS system services on Apple Silicon Macs to maximize AI inference performance. The name combines "smog" (the background service pollution choking your inference) and "toggle" (what you do to clear it). The backend runs on Milo (Linux Docker host) and communicates with target Macs via SSH.

Target hardware: **Apple Silicon (M-series) Macs only.** No Intel Mac support.

---

## Tech Stack

### Backend
- **Python 3.11+** with **FastAPI**
- **Paramiko** for SSH command execution on target Macs
- **SQLite** via **SQLModel** for settings, toggle state history, snapshots, and connection config
- **python-dotenv** for environment bootstrap (auto-generated by setup wizard, never hand-edited)
- **uvicorn** as ASGI server
- **Server-Sent Events (SSE)** via `sse-starlette` for real-time resource monitor push

### Frontend
- **React 18** with **Vite**
- **Tailwind CSS** for styling
- **shadcn/ui** component library
- **Lucide React** icons
- **Recharts** for resource monitoring sparklines
- Dark mode default, light mode toggle
- Mobile responsive

### Deployment
- **Docker Compose** on Milo — single container, SSH keys mounted read-only
- **Caddy** reverse proxy on Milo (existing) — `smoggle.perkinslab.com`
- Port: **7420** (confirmed available on Milo)
- Health check endpoint at `/health`

## SSH Setup

Include a **Setup Guide** page in the UI with copy-to-clipboard on every command and live test buttons.

### On each target Mac:
```bash
# Enable Remote Login (SSH)
sudo systemsetup -setremotelogin on

# Verify SSH is listening
sudo lsof -i :22
```

### On Milo (one-time per Mac):
```bash
# Generate dedicated key for MacToggle
ssh-keygen -t ed25519 -C "milo-smoggle" -f ~/.ssh/smoggle_ed25519

# Install public key on target Mac
ssh-copy-id -i ~/.ssh/smoggle_ed25519.pub tonyperkins@<MAC_IP>

# Test
ssh -i ~/.ssh/smoggle_ed25519 tonyperkins@<MAC_IP> echo "Smoggle connection OK"
```

### Passwordless sudo on each target Mac:
```bash
sudo visudo -f /etc/sudoers.d/smoggle
```

```
tonyperkins ALL=(ALL) NOPASSWD: /usr/sbin/mdutil, /usr/bin/tmutil, /usr/bin/pmset, /usr/sbin/softwareupdate, /bin/launchctl, /usr/bin/defaults
```

## Toggle Registry

### Toggle Data Model

| Field | Type | Description |
|---|---|---|
| `id` | str | Unique identifier |
| `name` | str | Display name |
| `description` | str | One-line description |
| `purpose` | str | What this service does |
| `impact` | str | Performance impact when ON during inference |
| `default_state` | str | Apple's default: "on" or "off" |
| `danger` | int | 0=safe, 1=caution, 2=danger |
| `requires_restart` | bool | True if toggle requires app/session restart |
| `restart_note` | str | What needs restarting and why |
| `profiles` | list | Which profiles include this toggle |
| `apple_silicon_only` | bool | Always True |
| `cmd_off` | str | Shell command to disable |
| `cmd_on` | str | Shell command to enable |
| `cmd_status` | str | Returns "1" if ON, "0" if OFF |

### Status Command Reliability Standard

All `cmd_status` commands must:
- Return exactly `"1"` (on) or `"0"` (off) — no extra whitespace
- Use `|| echo 0` / `|| echo 1` fallbacks for missing plists or first-run
- Use exit code checks (`grep -q ... && echo 1 || echo 0`), never `grep -c` alone
- Handle macOS Ventura (13), Sonoma (14), Sequoia (15)

## Profiles

### 🔄 Default — Reset to Apple Defaults
Restores every toggle to `default_state`. No confirmation required.

### ⚡ Performance Mode
spotlight, timemachine, icloud_sync, photos_analysis, siri, auto_updates, power_nap, handoff, mail_fetch, analytics

Safe only. No breakage risk. Recommended for daily inference use.

### 🚀 Max Mode
All Performance toggles + ollama, app_nap, high_power_mode, location_services, airplay_receiver

Single confirmation dialog. May affect AirPlay receiving and location features.

### ☢️ Hyper Mode
All Max toggles + notification_center, mdns

**Breaks:** AirDrop, AirPlay to this Mac, some HomeKit.
Requires typing `"HYPER"` in confirmation input. Each danger=2 toggle lists exactly what breaks in red.

## UI Requirements

### Layout
- **Top navbar:** "Smoggle" wordmark, **target Mac dropdown** (multi-Mac, v1), connection status dot per selected target, dark/light toggle
- **Left sidebar:** Profile buttons (Default/Performance/Max/Hyper), Snapshots section, Settings, Setup Guide, History

### Toggle Cards
- Name + description
- ON (green) / OFF (gray) state chip
- Impact badge: HIGH=red, MEDIUM=amber, LOW=blue
- Danger badge: ⚠ CAUTION (amber) / 🔴 DANGER (red)
- Apple default chip: "Default: ON/OFF"
- ⚡ Restart Required badge with tooltip showing `restart_note`
- Toggle switch with optimistic UI + live confirmation
- Last changed (relative timestamp)

### Resource Monitor Strip (SSE real-time push, every 3 seconds)
Compact stat pills pinned to top of main content:
- CPU % with sparkline (last 60s)
- Memory used / total GB
- Swap used — red if > 0, green if 0
- **Inference Server status** — auto-detects whichever is running:
  - Checks `pgrep -x ollama` and `pgrep -f mlx_lm.server` independently
  - Shows **"Ollama ●"** (green) / **"MLX ●"** (green) / **"None ○"** (gray)
  - If **both running simultaneously**: shows both with **amber ⚠ warning** — memory pressure risk on 16GB machines

1. Preview modal: toggle diff list
2. ⚡ flags on restart-required toggles
3. Red warnings for danger=2 toggles listing what breaks
4. Hyper: type "HYPER" to enable Apply button

## Executor Abstraction

```python
# backend/auth.py
# TODO: Implement authentication in v2
# Planned approach: Basic Auth via Caddy reverse proxy
# v1: unauthenticated — deploy on trusted internal network only

async def get_current_user():
    """Auth stub — always returns anonymous in v1."""

# backend/executor.py
from abc import ABC, abstractmethod

class BaseExecutor(ABC):
    @abstractmethod
    def run(self, command: str) -> tuple[str, str, int]:
        """Returns (stdout, stderr, exit_code)"""
        pass

    @abstractmethod
    def test_connection(self) -> bool:
        pass

class SSHExecutor(BaseExecutor):
```

## State Management

- SQLite single source of truth for config and history
- Toggle state always read live from Mac on page load and after each apply
- Optimistic UI reverts on SSH command failure
- SSE pushes resource stats every 3s — no client polling
- Profile applies run sequentially — no parallel launchctl calls

## Error Handling

| Scenario | Behavior |
|---|---|
| SSH connection lost | Red banner + auto-retry every 30s |
| SSH command fails | Toast with stderr + toggle reverts |
| Sudo denied | Inline card error with Setup Guide link |
| Plist not found | Card shows "Not applicable on this Mac" |
| Unknown macOS | Warning banner |
| All errors | Logged to SQLite with full stderr |

## Design Notes
